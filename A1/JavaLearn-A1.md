#### （二）、注释

##### 1、介绍

​	注释是写在程序中对代码进行解释说明的文字，方便自己和他人查看，以便了解程序。

```java
	//这是一个单行注释，有效范围是从//开始到行末

     /*
     这是一个多行注释，有效范围是从/*开始 到*/结束
    */
         
    /**
     * 这是一个文档注释，有效范围是从/**开始 到*/结束
     */
}
```

##### 2、特点

```
不会影响程序的执行，编译后的class文件中已经没有注释了
```

##### 3、区别

| 注释类型            | 区别                                                         |
| :------------------ | :----------------------------------------------------------- |
| 单行：//            | 只需要注释一行时使用                                         |
| 多行注释：/*    */  | 需要注释多行时使用                                           |
| 文档注释：/**    */ | 一般用在类、方法、成员变量上，且在其上的注释内容会被提取到程序说明文档中 |

#### （四）、变量

##### 1、介绍

```
变量就是内存中的一块区域，用来装程序要处理的数据
```


##### 4、特点

##### 5、存储原理

```
1、都是采用二进制，使用0和1，按照逢2进1的规则表示数据来存储
2、字符数据：字符存的是ASCII表中对应的数字的二进制形式
3、图片：图片存储就是把画面切成网格，在每个格子里记录该位置的颜色值（RGB整数）。分辨率决定空间细度，位深度决定颜色精细度，文件格式决定是否压缩。
4、音频：声音存储就是把连续波形的每个瞬间高度，用定时快照+近似取整的方式，变成一长串二进制整数。采样率决定时间精度，位深度决定幅度精度，文件格式决定是否压缩。
```

##### 1、介绍

```

```

#### （八)、类型转换

##### 1、介绍

```
存在不同类型的变量赋值给其他类型的变量，称为类型转换。
```

##### 2、分类

```
1、自动类型转换
	类型范围小的变量，可以直接赋值给类型范围大的变量
2、强制类型转换
	类型范围大的变量，不可以直接赋值给类型范围小的变量，需要使用强制类型转换
```

##### 3、注意

```
强制类型转换可能造成数据（丢失）溢出，浮点型强转成整数，直接丢掉小数部分，保留整数部分返回
```

####  （九）、表达式的自动类型提升

##### 1、介绍

```
在表达式中，小范围类型的变量，会自动转换成表达式中较大范围的类型，再次参与运算
```

##### 2、注意事项

```
1、表达式的最终结果类型由表达式中的最高类型决定
2、在表达式中，byte、short、char是直接转换成int类型参与运算的
```

##### 1、算数运算符

##### 2、自增自减

| 符号     | 作用                                       |
| -------- | ------------------------------------------ |
| 自增：++ | 放在某个变量前面或者后面，对变量自身的值+1 |
| 自减：-- | 放在某个变量前面或者后面，对变量自身的值-1 |

###### 2.1、注意事项

```Java
1、++、--：如果在变量前后单独使用是没有区别的
2、++、--如果不是单独使用（如在表达式中或同时有其他操作）放在变量前后会存在明显区别
    在变量前面，先对变量+1/-1，再用变量的值运算
    int a = 10;
	int rs = ++a;(先加再用)
	再变量的后面，先拿变量的值运算，在对变量的值+1/-1
    int b = 10;
	int rs = b++;（先用后加）
```

##### 6、逻辑运算符

| ---- | -------- | -------------- | ------------------------------------------------------------ |

| \|   | 逻辑或   | 2 > 1 \| 3 < 5 | 多个条件中只要有一个是true，结果就是true                     |

| ^    | 逻辑异或 | 2>1 ^ 3>1      | 前后条件的结果相同，就直接返回false，前后条件的结果不同，才返回true |
| &&   | 短路与   | 2>10 && 3>2    | 判断结果与"&"一样，过程不同：左边为false，右边则不执行       |

#### （十二）、程序流程控制

##### 1、分类

```
1、顺序结构：自上而下的执行程序
2、分支结构：根据条件，选择对应的代码执行
3、循环结构：控制某段代码重复的执行
```

##### 2、if分支结构

```java
1、根据条件的真或假，来决定执行某段代码
2、格式
	if(条件表达式){
        代码;
    }
	
	if(条件表达式){
        代码1;
    } else {
        代码2;
    }

	if(条件表达式1){
        代码1;
    } else if(条件表达式2){
        代码2;
    }else if(条件表达式3){
        代码3;
    }
	...
    else {
        代码n;
    }
3、if语句中如果只有一行代码，大括号可以省略不写
```

##### 3、switch分支结构

```Java
1、通过比较值是否相等，来决定执行哪条分支
2、格式
	switch(表达式){
		case 值1:
			执行代码...;
		break；
		case 值2:
			执行代码...;
		break；
		...
		default：
			执行代码n;
	}
3、执行流程
	先执行表达式的值，再拿这个值去与case后的值进行匹配
	与那个case后的匹配为true就执行哪个case块的代码，遇到break就跳出switch分支
	如果全部case后的值都是false，则执行default块里的代码
4、注意：
	表达式类型只能是byte、short、int、char,JDK5开始支持枚举，JDK7开始支持String，不支持doubel、	flaot、long
	case给出的值不允许重复，且只能是字面量，不能是变量
	正常使用switch的时候，不要忘记写break，否则会出现穿透的现象
5、switch穿透性能解决问题：
    存在多个case分支的代码时一样时，可以把代码写到一个case块，其他case块通过穿透性能，穿透到该case块即可，这样可以简化代码
```

##### 4、if和switch区别：适合的业务场景

```
1、if在功能上远远强大与switch
2、当前条件是区间的时候，建议使用if分支结构来实现
3、当条件是与一个一个的值比较的时候，建议用switch更合适（格式良好、性能较好）
```

##### 5、for循环

```java
1、控制一段代码反复执行多次
2、格式
	for(初始化语句; 循环条件; 迭代语句){

```

##### 6、while循环

```
1、格式

	while(循环条件){
		循环体语句(被重复执行的代码);
```

##### 7、for和while的使用时机

```
1、功能上时完全一样的，for能解决的while也能解决
2、使用规范：
	知道几次循环用for
	不知道几次循环用while
```

##### 8、do-while循环

```
1、格式

	do{

2、特点：先执行，后判读
```

##### 9、注意

```
1、for循环中，控制循环的变量只能在循环中使用，while循环中，控制循环的变量在循环后还可以使用
```

##### 10、死循环

```
1、可以一直执行下去的一种循环，如果没有干预不会停下来
2、写法
	for(;;){
		执行代码;
	}
	
	while(true){
		执行代码;
	}
	
	do{
		执行代码;
	}while(true);
```

##### 11、循环嵌套

```
1、外部循环执行一次，内部循环会全部执行完一轮
```

##### 12、break、coutinue

```
1、break： 跳出并结束当前所在循环的执行
		  只能用于结束所在循环，或者结束所在switch分支的执行
2、continue：用于跳出当前循环的当次执行，直接进入下一次循环
			只能在循环中使用
```

#### （十五）、面向对象

##### 1、对象

```
对象本质上是一种特殊的数据结构(可以理解成一张表)
对象是用类new出来的，有了类就可以创建出对象
```

##### 2、基本语法

```java
1、构造器
	public class Student{
		/**构造器*/
        public Student(){
            ...
        }
	}
2、没有返回值 构造器名称和类名一致
3、特点：创建对象时，对象会去调用构造器
4、应用场景：创建对象时，同时完成对对象成员变量（属性）的初始化赋值
5、注意事项：类默认就自带了一个无参构造器
    	如果为类定义了有参构造器，类默认的无参构造器就没有了，此时如果还想用无参构造器，就必须自己手写一个无		  参构造器
```

```
1、this
	this就是一个变量，可以用在方法中，来拿到当前对象（哪个对象调用这个方法，this就拿到哪个对象）
应用场景：this主要解决变量名称冲突的问题
```

```
1、封装
	面向对象三大特征：封装、继承、多态
	类就是一种封装
2、设计要求
	合理隐藏，合理暴露
3、隐藏
	使用private关键字修饰成员变量，就只能在本类中背直接访问
	其他任何地方不能直接访问
4、暴露
	使用public修饰的get和set方法合理暴露成员变量的取值和赋值
```

```
1、JavaBean
	是一种特殊类，类中要满足如下需求
		类中的成员变量全部私有，并提供public修饰的getter和setter方法
		类中需要提供一个无参构造器，有参构造器可选
2、应用场景
	实体类的对象只负责数据存取，而对数据的业务处理交给其他类的对象来完成，以实现数据和数据业务处理相分离
```

```
1、static
	静态，可以修饰成员变量，成员方法
2、成员变量按照有无static修饰分为两种
	静态变量（类变量）
		有static修饰，属于类，在计算机里只有一份，会被类的全部对象共享
	实例变量（对象变量）
		无static修饰，属于每个对象
3、应用场景
	如果某个数据只需要一份，且希望能够被共享（访问、修改），则该数据可以定义成静态变量来记住
4、修饰方法
	分类
		静态方法：有static修饰的成员方法，属于类
			如果这个方法只是为了做一个功能且不需要直接访问对象数据，这个方法直接定义成具静态方法
			常见应用场景是做工具类
				工具类：工具类中的方法都是一些静态方法，每个方法用来完成一个功能，以便供给开发人员使用
				好处
					提高代码的复用，调用方便，提高开发效率
					直接用类目调用即可，调用方便，也节省内存
		实例方法：无static修饰的成员方法，属于对象
			如果这个方法是对象的行为，需要访问对象的数据，这个方法必须定义成实例方法
			实例方法需要创建对象来调用，此时对象只是为了调用方法，对象占内存，这样会浪费内存
5、多学一招
	工具类没有创建对象的需求，建议将工具类的构造器进行私有
6、注意事项
	静态方法中可以直接访问静态成员，不可以直接访问实例成员
	实例方法中既可以直接访问静态成员，也可以直接访问实例成员
	实例方法中可以出现this关键字，静态方法中不可以出现this关键字
```

##### 3、继承

```java
1、什么是继承
	Java中提供了一个关键字extends，用这个关键字，可以让一个类和另一个类建立起父子关系
	子类能继承父类的非私有成员（成员变量、成员方法）
2、格式
	public class B entends A{
	
	}
3、权限修饰符
    就是用来限制类中的成员（成员变量、成员方法、构造器）能够被访问的范围
    private 只能本类
    缺省 本类、同一个包中的类
    protected 本类、同一个包中的类、子孙类中
    public 任意位置
4、特点
    单继承：Java是单继承模式，一个类只能继承一个直接父类
    多层继承：Java不支持多继承、但支持多层继承
    祖宗类：Java中所有的类都是object类的子类
    就近原则：优先访问自己类中，自己类中没有的才会访问父类
    可以通过super关键字，指定访问父类的成员
5、重写
    当子类觉得父类中的某个方法不好用，或者无法满足自己的需求时，子类可以重写一个方法的名称，参数列表一样的方法，去覆盖父类的这个方法，这就是方法重写
    技巧：使用override注解，他可以指定Java编译器，检查我们方法重写的格式是否正确
    注意事项：子类重写父类方法时，访问权限必须大于或者等于父类该方法的权限（public>protected>缺省）
    		重写的方法返回值，必须与被重写方法的返回值类型一样，或者范围更小
    		私有方法、静态方法不能被重写，如果重写会报错
    规范：声明不变，重新实现、
6、子类构造器
    特点：子类的全部构造器，都会先调用父类的构造器，再执行自己的
    实现：默认情况下，子类全部构造器的第一行代码都是super（）（写不写都有），他会调用父类的无参构造器
    	 如果父类美哟无参构造器，则我们必须在子类构造器的第一行手写super（...），指定去调用父类的有参构造器
7、补充
    任意类的构造器中，是可以通过this（...）区调用该类的其他构造器的
    super（...）和this（...）必须写在构造器的第一行，而且两者不能同时出现
```

##### 4、多态

```
1、什么是多态
	多态实在继承\实现情况下的一种现象，表现为：对象多态，行为多态
	方法：编译看左边，运行看右边
	成员变量：编译看左边，运行也看左边
2、前提
	有继承/实现关系，存在父类引用子类对象，存在方法重写
3、注意事项
	多态是对象、行为的多态，在Java中的属性（成员变量）不谈多态
4、好处
	在多态形式下，右边对象是解耦合的，更便于拓展和维护
	定义方法时，使用父类类型的形参，可以接受一切子类对象，扩展性更强，更便利
5、问题：
	多态下不能使用子类的独有功能
6、多态下的类型转换
	自动类型转换	父类 变量名 = new 子类（）;
	强制类型转换	子类 变量名 = （子类）父类变量;
	注意事项
		存在继承/实现关系就可以在编译阶段进行强制类型转换，编译阶段不会报错
		运行时，如果发现对象的真实类型与强转后的类型不同，就会报类型转换异常（ClassCastException)
	Java建议：使用instanceof关键字，判断当前对象的真实类型在进行强转
```

##### 5、final

```
1、认识final
	final关键字的意思是最终的意思，可以修饰：类、方法、变量
	final修饰静态变量，这个变量今后被称为常量，可以记住一个固定值，并且程序中不能修改了，通常这个值作为系统的配置信息
	修饰类：该类被成为最终类、特点是不能被继承了
	修饰方法：该方法被称为最终方法，特点是不能被重写了
	修饰变量：该变量有且仅能被赋值一次
2、注意
	final修饰基本类型的变量，变量存储的数据不能被改变
	final修饰引用类型的变量，变量存储的地址不能被改变，但地址所指向对象的内容是可以被改变的
3、常量
	使用了 static final 修饰的成员变量就是常量
	作用：常用于记录系统配置的信息
	常量的名称建议全部大写，多个单词用下划线链接
	优势：代码可读性好，可维护性也高
	执行原理：程序编译后，常量会被“宏替换”，出现常量的地方全部会被替换成其记住的字面量，这样可以保证使用常量和字面量的性能是一样的
```

##### 8、抽象类

```java
1、认识
	在Java中有一个关键字：abstract,他就是抽象的意思，可以用它修饰类、成员方法
	abstract修饰类，这个类就是抽象类
	abstract修饰方法，这个方法就是抽象方法
2、格式
	修饰符 abstract class 类名{
		修饰符 abstract 返回值类型 方法名称（形参列表）；
	}
	public abstract class A{
        public abstract void show();
    }
3、特点、注意事项
    抽象类中不一定要有抽象方法，有抽象方法的类必须是抽象类
    类有的成员：成员变量，方法，构造器，抽象类都可以有
    抽象类最主要的特点：抽象类不能创建对象，仅作为一种特殊的父类，让子列继承并实现
    一个类继承抽象类，必须重写玩抽象类的全部抽象方法，否则这个类也必须定义成抽象类
4、好处
    父类知道每个子类都要做某个行为，但每个子类要做的情况不一样，父类就定义成抽象方法，交给子类去重写实现
    设计这样的抽象类就是为了更好的支持多态
5、模板方法设计模式
    提供一个方法作为完成某类方法的模板，模板方法封装了每个实现步骤，但允许子类提供特定步骤的实现
    可以提高代码的复用，并简化子类设计
    写法：
    	定义一个抽象类
    	在里面定义两个方法
    		一个是模板方法，把共同的实现步骤放里面去
    		一个是抽象方法，不确定的实现步骤，交给具体的子类来完成
    建议使用final关键字修饰抽象方法
    	模板方法是给子类直接使用的，不能被子类重写
    	一旦子类重写了模板方法，模板方法就失效了
```

##### 9、接口

```java
1、概述
	java提供了一个关键字interface定义出接口
    接口不能创建对象
    接口是用来被类实现(implements)的，接口的类称为实现类，一个类可以同时实现多个接口
2、格式
    public interface 接口名{
    	//成员变量）（常量）
    	//常用方法（抽象方法）
	}

	修饰符 class 实现类类名 implements 接口1、接口2、接口3，...{
        //实现类实现多个接口，必须重写完全部接口的全部抽象方法，否则实现类需要定义成抽象类
    }
3、好处
    弥补了类单继承的不足，一个类同时可以实现多个接口，是类的角色更多，功能更强大
    让程序可以面向接口编程，这样程序员就可以灵活方便的切换各种业务实现（更利于程序的解耦合）
    接口可以实现面向接口编程，更利于解耦合
4、Jdk8开始接口新增的三种方法
    默认方法（实例方法）
    	使用default修饰，默认会被加上public修饰
    	注意：只能使用接口的实现类调用对象
    default void show(){
    	...
	}
	
	私有方法
        必须使用private修饰（JDK9开始支持）
    private void show(){
        ...
    }

	类方法（静态方法）
        使用static修饰，默认会被加上public修饰
        注意：只能用接口名来调用
   	static void show(){
    	...    
    }
5、注意事项
    接口与接口可以多继承，一个接口可以同时继承多个接口[重点]
    一个接口继承多个接口，如果多个接口中存在方法签名冲突，则此时不持支多继承，也不支持多实现
    一个类继承了父类，又同时实现了接口，如果父类中的接口中有同名的默认方法，实现列会优先用父类的
    一个类实现了多个接口，如果多个接口中存在同名的默认方法，可以不冲突，这个类重写该方法即可
```

##### 10、接口与抽象类的区别

```Java
1、相同点：
    都是抽象形式，都可以有抽象方法，都不能创建对象
    都是派生形式，抽象列是被子类继承使用，接口时被实现派生
    继承抽象类或者实现接口，都必须重写完他们的抽象方法，否则自己要称为抽象类或者报错
    都能支持多态，都能够实现解耦合
2、不同点
    抽象类中可以定义类的全部普通成员，接口只能定义常量、抽象方法（JDK8新增的三种方式）
    抽象类只能被类单继承，接口可以被类多实现
    一个类继承抽象类就不能在继承其他类，一个类实现列接口还可以继承其他类或者实现其他接口
    抽象类体现模板思想，更利于做父类，实现代码的复用性
    接口更适合做功能的解耦合，解耦合性更强更灵活
```
