##### （二）、注释

1、介绍：注释是写在程序中对代码进行解释说明的文字，方便自己和他人查看，以便了解程序。

```java
	//这是一个单行注释，有效范围是从//开始到行末

     /*
     这是一个多行注释，有效范围是从/*开始 到*/结束
    */
         
    /**
     * 这是一个文档注释，有效范围是从/**开始 到*/结束
     */
}
```

2、特点：不会影响程序的执行，编译后的class文件中已经没有注释了

3、区别

| 注释类型            | 区别                                                         |
| :------------------ | :----------------------------------------------------------- |
| 单行：//            | 只需要注释一行时使用                                         |
| 多行注释：/*    */  | 需要注释多行时使用                                           |
| 文档注释：/**    */ | 一般用在类、方法、成员变量上，且在其上的注释内容会被提取到程序说明文档中 |

##### （三）、字面量

1、介绍：Java 字面量就是代码里直接写死的固定值，不用计算就知道代表什么数据 。

2、分类

| 常用数据       | 生活中的写法 | 程序中的写法  | 说明                                       |
| :------------- | :----------- | :------------ | :----------------------------------------- |
| 整数           | 666，-8      | 666，-8       | 写法一致                                   |
| 小数           | 3.14，-3.14  | 3.14，-3.14   | 写法一致                                   |
| 字符           | A，0，我     | 'A'，'0'，'m' | 程序中必须使用一个单引号，且只能有一个字符 |
| 字符串         | HelloWorld   | "HelloWorld"  | 程序中必须使用一个双引号，内容可有可无     |
| 布尔值         | 真，假       | true，false   | 只有两个值，true代表真，false代表假        |
| 空值           | -            | null          | 一个特殊值，空值                           |
| 特殊字符字面量 | -            | \t，\n        | -                                          |

##### （四）、变量

1、介绍：变量就是内存中的一块区域，用来装程序要处理的数据

2、格式

```tex
数据类型 变量名 = 值;
```

3、好处：使用变量记录处理的数据，编写的代码更加灵活，管理代码更加方便

4、特点：变量里的数据可以被替换

5、存储原理

```
1、都是采用二进制，使用0和1，按照逢2进1的规则表示数据来存储
2、字符数据：字符存的是ASCII表中对应的数字的二进制形式
3、图片：图片存储就是把画面切成网格，在每个格子里记录该位置的颜色值（RGB整数）。分辨率决定空间细度，位深度决定颜色精细度，文件格式决定是否压缩。
4、音频：声音存储就是把连续波形的每个瞬间高度，用定时快照+近似取整的方式，变成一长串二进制整数。采样率决定时间精度，位深度决定幅度精度，文件格式决定是否压缩。
```

##### （六）、标识符

1、介绍：标识符是程序中用来唯一标识变量、方法、类、接口、数组等名称

2、规则

```
1、一般由数字、字母、下划线（_）、和美元符号（$）组成
2、不能以数字开头、不能是关键字、不能包含一些特殊字符（&、%、#...)
3、变量名：建议首字母小写，后面每个单词首字母大写（小驼峰）
		 建议首字母大写，后面每个单词首字母大写（大驼峰）
```

##### （七）、关键字

1、介绍：关键字是编程语言中预定义的具有特殊意义的单词。这些单词被保留，不能用作标识符来命名变量。

##### （七）、方法

1、介绍：一种用于执行特定任务或操作的代码块，代表一个**功能**，它可以接收数据进行处理，并返回一个处理后的结果

2、格式

```Java
修饰符 返回值类型 方法名（形参列表）{
    方法体代码（需要执行的功能代码）
    return 返回值；
}
```

3、调用

```java
方法名（参数列表）
```

3、注意事项

```
1、方法的返回值：无返回值void类型和有返回值的数据类型。
2、方法的参数：无参数、有参数。
3、方法可以重载：一个类中，出现多个方法名相同，但是他们的参数列表是不同的，那么这些方法就称为方法重载
4、无返回值的方法中可以通过单独的return立即结束当前方法的执行
```

##### （八)、类型转换

1、介绍：存在不同类型的变量赋值给其他类型的变量，称为类型转换。

2、分类

```
1、自动类型转换
	类型范围小的变量，可以直接赋值给类型范围大的变量
2、强制类型转换
	类型范围大的变量，不可以直接赋值给类型范围小的变量，需要使用强制类型转换
```

3、注意：强制类型转换可能造成数据**（丢失）溢出**，浮点型强转成整数，**直接丢掉小数部分，保留整数部分返回**

#####  （九）、表达式的自动类型提升

1、介绍：在表达式中，小范围类型的变量，会自动转换成表达式中较大范围的类型，再次参与运算

2、注意事项

```
1、表达式的最终结果类型由表达式中的最高类型决定
2、在表达式中，byte、short、char是直接转换成int类型参与运算的
```

#####  （十一）、运算符

1、算数运算符

| 符号 | 作用 | 说明                                       |
| ---- | ---- | ------------------------------------------ |
| +    | 加   | 两数相加                                   |
| -    | 减   | 两数相减                                   |
| *    | 乘   | 两数相乘                                   |
| /    | 除   | 两数相除，在Java中两个整数相除结果还是整数 |
| %    | 取余 | 获取的是两个数据做除法的余数               |

2、自增自减

| 符号     | 作用                                       |
| -------- | ------------------------------------------ |
| 自增：++ | 放在某个变量前面或者后面，对变量自身的值+1 |
| 自减：-- | 放在某个变量前面或者后面，对变量自身的值-1 |

2.1、注意事项

```Java
1、++、--：如果在变量前后单独使用是没有区别的
2、++、--如果不是单独使用（如在表达式中或同时有其他操作）放在变量前后会存在明显区别
    在变量前面，先对变量+1/-1，再用变量的值运算
    int a = 10;
	int rs = ++a;(先加再用)
	再变量的后面，先拿变量的值运算，在对变量的值+1/-1
    int b = 10;
	int rs = b++;（先用后加）
```

3、赋值运算符

| 符号 | 用法       | 作用       | 底层代码形式            |
| :--- | :--------- | :--------- | :---------------------- |
| =    | int a = 10 | 赋值       | -                       |
| +=   | a+=b       | 加后赋值   | a = （a的类型）（a + b) |
| -=   | a-=b       | 减后赋值   | a = （a的类型）（a - b) |
| *=   | a*=b       | 乘后赋值   | a = （a的类型）（a * b) |
| /=   | a/=b       | 除后赋值   | a = （a的类型）（a / b) |
| %=   | a%=b       | 取余后赋值 | a = （a的类型）（a % b) |

注意：除了"="以外的赋值运算符隐含了强制类型转换

4、关系运算符

| 符号 | 例子 | 作用               | 结果                              |
| ---- | ---- | ------------------ | --------------------------------- |
| >    | a>b  | 判断a是否大于b     | 结果成立返回true，不成立返回false |
| >=   | a>=b | 判断a是否大于等于b | 结果成立返回true，不成立返回false |
| <    | a<b  | 判读a是否小于b     | 结果成立返回true，不成立返回false |
| <=   | a<=b | 判读a是否小于等于b | 结果成立返回true，不成立返回false |
| ==   | a==b | 判断a是否等于b     | 结果成立返回true，不成立返回false |
| !=   | a!=b | 判读a是否不等于b   | 结果成立返回true，不成立返回false |

5、三元运算符

```
格式：条件表达式 ? 值1 : 值2;
执行流程：首先计算关系表达式的值，如果值为true，返回值1，如果为false，返回值2
```

6、逻辑运算符

| 符号 | 叫法     | 例子           | 运算逻辑                                                     |
| ---- | -------- | -------------- | ------------------------------------------------------------ |
| &    | 逻辑与   | 2 > 1 & 3 > 2  | 多个条件必须都是true，结果才是true；有一个是false，结果就是false |
| \|   | 逻辑或   | 2 > 1 \| 3 < 5 | 多个条件中只要有一个是true，结果就是true                     |
| !    | 逻辑非   | !(2 > 1)       | 就是取反，!true == false、!fasle == true                     |
| ^    | 逻辑异或 | 2>1 ^ 3>1      | 前后条件的结果相同，就直接返回false，前后条件的结果不同，才返回true |
| &&   | 短路与   | 2>10 && 3>2    | 判断结果与"&"一样，过程不同：左边为false，右边则不执行       |
| \|\| | 短路或   | 2>1 \|\| 3<5   | 判断结果与"\|"一样，过程不同：左边为true，右边则不执行       |

##### （十二）、程序流程控制

1、分类

```
1、顺序结构：自上而下的执行程序
2、分支结构：根据条件，选择对应的代码执行
3、循环结构：控制某段代码重复的执行
```

2、if分支结构

```java
1、根据条件的真或假，来决定执行某段代码
2、写法
	if(条件表达式){
        代码;
    }
	
	if(条件表达式){
        代码1;
    } else {
        代码2;
    }

	if(条件表达式1){
        代码1;
    } else if(条件表达式2){
        代码2;
    }else if(条件表达式3){
        代码3;
    }
	...
    else {
        代码n;
    }
3、if语句中如果只有一行代码，大括号可以省略不写
```
