##### （二）、注释

1、介绍：注释是写在程序中对代码进行解释说明的文字，方便自己和他人查看，以便了解程序。

```java
	//这是一个单行注释，有效范围是从//开始到行末

     /*
     这是一个多行注释，有效范围是从/*开始 到*/结束
    */
         
    /**
     * 这是一个文档注释，有效范围是从/**开始 到*/结束
     */
}
```

2、特点：不会影响程序的执行，编译后的class文件中已经没有注释了

3、区别

|      注释类型       |                             区别                             |
| :-----------------: | :----------------------------------------------------------: |
|      单行：//       |                     只需要注释一行时使用                     |
| 多行注释：/*    */  |                      需要注释多行时使用                      |
| 文档注释：/**    */ | 一般用在类、方法、成员变量上，且在其上的注释内容会被提取到程序说明文档中 |

##### （三）、字面量

1、介绍：Java 字面量就是代码里直接写死的固定值，不用计算就知道代表什么数据 。

2、分类

|    常用数据    | 生活中的写法 | 程序中的写法  |                    说明                    |
| :------------: | :----------: | :-----------: | :----------------------------------------: |
|      整数      |   666，-8    |    666，-8    |                  写法一致                  |
|      小数      | 3.14，-3.14  |  3.14，-3.14  |                  写法一致                  |
|      字符      |   A，0，我   | 'A'，'0'，'m' | 程序中必须使用一个单引号，且只能有一个字符 |
|     字符串     |  HelloWorld  | "HelloWorld"  |   程序中必须使用一个双引号，内容可有可无   |
|     布尔值     |    真，假    |  true，false  |    只有两个值，true代表真，false代表假     |
|      空值      |      -       |     null      |              一个特殊值，空值              |
| 特殊字符字面量 |      -       |    \t，\n     |                     -                      |

##### （四）、变量

1、介绍：变量就是内存中的一块区域，用来装程序要处理的数据

2、格式

```tex
数据类型 变量名 = 值;
```

3、好处：使用变量记录处理的数据，编写的代码更加灵活，管理代码更加方便

4、特点：变量里的数据可以被替换

5、存储原理

```
1、都是采用二进制，使用0和1，按照逢2进1的规则表示数据来存储
2、字符数据：字符存的是ASCII表中对应的数字的二进制形式
3、图片：图片存储就是把画面切成网格，在每个格子里记录该位置的颜色值（RGB整数）。分辨率决定空间细度，位深度决定颜色精细度，文件格式决定是否压缩。
4、音频：声音存储就是把连续波形的每个瞬间高度，用定时快照+近似取整的方式，变成一长串二进制整数。采样率决定时间精度，位深度决定幅度精度，文件格式决定是否压缩。
```

##### （六）、标识符

1、介绍：标识符是程序中用来唯一标识变量、方法、类、接口、数组等名称

2、规则

```
1、一般由数字、字母、下划线（_）、和美元符号（$）组成
2、不能以数字开头、不能是关键字、不能包含一些特殊字符（&、%、#...)
3、变量名：建议首字母小写，后面每个单词首字母大写（小驼峰）
		 建议首字母大写，后面每个单词首字母大写（大驼峰）
```

##### （七）、关键字

1、介绍：关键字是编程语言中预定义的具有特殊意义的单词。这些单词被保留，不能用作标识符来命名变量。
